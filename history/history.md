# 历史版本

---

## v1.0.11

- 构建调整：签名材料不再写死在源码里，改为从环境变量或本地 `local.properties` 读取；GitHub Actions 未配置签名 secret 时改用随机生成的一次性密钥，避免仓库里出现明文密码。
- 功能与 v1.0.10 完全一致，本版仅涉及打包与签名流程。

## v1.0.10

- 保活权限改为**手动逐项确认**：系统没有查询「自启动」「耗电管理」真实状态的接口，软件不再猜测，一律以你亲手点过的为准。进入设置页时全部显示未获得，点一次确认一项；已确认的仍可再点重新跳转。
- MAC 地址必须点击输入框右侧的「完成」按钮确认后才能保存，未确认时输入框下方显示红字提示；修改已输入的 MAC 会自动重置确认状态。编辑已有设备时视为已确认。
- 编辑页右上角新增「删除」，删除前弹窗二次确认。
- 主页新增操作提示：「长按卡片删除，点击插头按钮以唤醒设备」。
- 唤醒弹窗底部补充说明，告知本次已尝试发出哪些报文。

## v1.0.9

- **移除回包探测**：不再监听 UDP 回包、不再做端口扫描，唤醒后只展示「发了什么」。WOL 本身是单向协议，探测带来的等待与误判大于收益。
- 日志改为保留 5 份轮转（`starwol.log` 加 `starwol.1` ~ `starwol.4`），单份超过 512 KB 自动滚动。
- 设置页日志区新增下拉选择，可在「当前记录」与历史 4 份之间切换查看，切换查看不影响正在记录的当前日志。
- 导出按钮改名为「导出当前展示日志」，导出内容与你正在看的那一份一致。

## v1.0.8

- 移除「自动获取 MAC」：Android 10 起普通应用读不到 ARP 表，功能在真机上不可用，改回手动填写。
- 唤醒前的连通性诊断改为 ICMP 语义：能读到 TTL、往返耗时、主机不可达、网络不可达、请求超时等具体原因。
- ping 的原始输出写入日志，便于排查网络问题。
- 修复页面转场方向：前进时新页面从右侧进入，后退时旧页面向右退出，与系统手势方向一致。

## v1.0.7

- 唤醒弹窗新增**原始报文展示**：以 hexdump 形式显示实际发出的 magic packet，以及收到的 UDP 回包、TCP banner，格式接近抓包工具，方便确认报文内容是否正确。

## v1.0.6

- 编辑页 MAC 输入框旁新增「自动获取」按钮：先读系统 ARP 表，未命中则 ping 一次目标 IP 触发 ARP 解析后重查，查到后自动填入并格式化。

## v1.0.5

- **完整移除 root 模式**：删除工作模式切换、root 命令执行、撤销、Magisk 守护模块等全部相关代码（12 个文件，净删除约 700 行）。
- 保活统一为：权限申请 + 精确闹钟 + 复活闹钟。
- 设置页去掉「工作模式」分段选择器，进入即是保活权限列表。

## v1.0.4

- 唤醒图标改回**电源符号**（圆环开口 + 中间一竖），替换掉上一版的开关样式。
- 删除 JobScheduler 每 15 分钟的兜底唤醒，避免每天上百次无意义唤醒带来的耗电。
- root 保活删掉 `set-standby-bucket active`（该设置对定时唤醒无实际帮助，只剩耗电）。
- 自启动改为跳转各厂商的「自启动管理」页面，覆盖小米、OPPO、vivo、华为、荣耀、三星、一加、realme、魅族、努比亚等入口，找不到时回退到应用详情页。
- 后台运行限制改名「耗电管理 · 完全允许」，并支持跳转到各厂商的耗电管理页面。

## v1.0.3

- applicationId 改为 `com.no4num.wol`。
- 唤醒图标改为开关样式（已在 1.0.4 纠正回电源符号）。
- 新增 JobScheduler 15 分钟兜底、解锁后复活、服务被销毁时挂复活闹钟。
- 新增 Magisk 守护模块导出（已在 1.0.5 随 root 模式一并移除）。

## v1.0.2

- 顶部内容下移，避开状态栏与刘海。
- 适配系统返回键与返回手势，二级页面不再直接退回桌面。
- 卡片交互改版：去掉整卡点击唤醒，改为卡片右侧两个方形按钮 —— 左边唤醒、右边编辑。
- 新增**复活机制**：应用被从最近任务划掉后，由系统的闹钟广播把前台服务重新拉起来。
- 从 root 模式切回正常模式时，自动撤销之前通过 root 做过的改动。

## v1.0.1

- 新增**日志系统**：内存保留最近 300 条，同时可落盘到应用私有目录。
- 设置页新增日志区，含两个开关（界面上显示日志、写入日志文件），默认都开启。
- 支持导出日志为文本文件分享出去，也支持一键清空。
- root 保活命令从 6 条收敛到 4 条，且只针对本应用包名，移除了会影响整机安全的全局设置项。
- root 命令执行前有确认弹窗并展示将要执行的命令，执行后做一次只读核对，且支持一键撤销。
- 日志埋点覆盖应用启动、服务启动、WOL 发送、网络诊断结果、定时排期、设备增删改、设置变更、定时任务触发等环节。

## v1.0.0

首个可用版本。

- 基于 Kotlin + Jetpack Compose 的原生应用，深色主题。
- 主页以圆角卡片展示设备列表，无设备时显示空态，右下角圆形按钮添加设备。
- 添加/编辑页：设备名、IP、端口、MAC 四项必填；MAC 支持 `AABB-CCDD-EEFF`、`AA-BB-DD-CC-EE-FF`、`AABB:CCDD:EEFF`、`AA:BB:CC:DD:EE:FF` 等写法，自动归一化成统一格式，格式错误时在下方红字提示。
- 可选：单播发送完成后，再向 `255.255.255.255` 广播一遍 WOL 报文。
- 可选：定时自动唤醒，时间用无限循环的滚轮选择器选取，类似系统倒计时。
- 唤醒后做回包探测，展示是否收到设备响应（该功能已在 1.0.9 移除）。
- 设置页提供工作模式切换（正常 / root）与保活权限申请：通知、电池优化豁免、精确闹钟、自启动、耗电管理、无障碍（root 模式已在 1.0.5 移除）。
- 保活机制：前台服务 + 开机广播 + 无障碍服务兜底。
- 附带 GitHub Actions 打包流程，推送代码即自动构建 debug 与 release 两个 APK。
